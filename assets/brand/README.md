# Approved BK identity

`bk-approved.png` is the owner's original, unmodified approved image.

Production assets use a square 800 × 800 crop at (200, 224) of the original
1254 × 1254 image. This retains the dark background and the complete mark,
including the extended lower-left terminal, with about 8% horizontal padding.
No artwork was generated, traced, recolored, or redesigned.

Generated using the existing Sharp installation and Lanczos resizing:

- `src/app/icon.png`: 512 × 512
- `src/app/apple-icon.png`: 180 × 180
- `src/app/favicon.ico`: PNG frames at 16, 32, 48, and 64 pixels

Next.js App Router discovers these file-based icons automatically. The visible
header and navigation are unchanged.
